## 摘要
在便携式演示接口上的移动模仿学习面临两个耦合的瓶颈：受运动污染的动作标签以及在连续移动基座上由推理引起的执行延迟。最近的手腕安装接口降低了桌面数据收集的成本，但单一的手腕视角无法捕捉基座导航所需的全局上下文。添加一个身体安装的摄像头会纠缠人类行走与手部运动。同时，生成策略引入了数百毫秒的推理延迟，在此期间基座会超过预测的路径点，迫使在动作拼接处进行向后修正。本文提出了Mobile UMI，一种无需硬件设备的演示框架，通过三个组成部分来解决这两个不足。首先，一个双摄像头捕获系统记录以胸部为中心的全局上下文和以手腕为中心的局部交互，无需任何机器人存在。其次，一个基于ChArUco的一次性空间锚点统一了胸部和手部的视觉-惯性框架；然后相对于胸部重新表达手部姿态，以提取解耦的SE(3)操作和SE(2)基座轨迹。第三，一个异步递减时域执行器执行在线状态匹配：每个生成的动作块与当前物理姿态重新对齐，以便在执行前丢弃过期的路径点。整个系统在四个长时程家庭任务上进行了评估，每个任务进行100次试验，平均成功率达到83.8%。与ACT和扩散策略的对比对照显示，仅使用胸部相对标签就填补了大部分差距；在线状态匹配填补了剩余的差距。这些结果表明，在测试条件下，对于移动模仿学习，显式的运动学分解结合状态级延迟对齐提供了一种有效的解决方案，无需对底层策略类别进行架构更改。

## Abstract
Mobile imitation learning on portable demonstration interfaces faces two coupled bottlenecks: locomotion-contaminated action labels and inference-induced execution latency on a continuously moving base. Recent wrist-mounted interfaces lower the cost of tabletop data collection, yet a single wrist view does not capture the global context required for base navigation. Adding a body-mounted camera entangles human walking with hand motion. Meanwhile, generative policies introduce hundreds of milliseconds of inference latency, during which the base advances past predicted waypoints, forcing backward corrections at action splices. This paper presents Mobile UMI, a hardware-free demonstration framework that addresses both gaps through three components. First, a dual-camera capture system records chest-centric global context and wrist-centric local interaction without any robot present. Second, a one-shot ChArUco-based spatial anchor unifies the chest and hand visual-inertial frames; the hand pose is then re-expressed relative to the chest to extract decoupled SE(3) manipulation and SE(2) base trajectories. Third, an asynchronous receding-horizon executor performs online state matching: each generated action chunk is realigned with the current physical pose so that expired waypoints are discarded before execution. The full system is evaluated on four long-horizon household tasks, achieving an average success rate of 83.8% over 100 trials per task. Controlled comparisons against ACT and Diffusion Policy show that the chest-relative label alone closes much of the gap; online state matching closes the remainder. These results indicate that, for mobile imitation learning under the tested conditions, explicit kinematic factorization combined with state-level latency alignment provides an effective solution without requiring architectural changes to the underlying policy class.

## 1. 核心问题与整体含义（研究动机与背景）
移动机器人在非结构化环境（如家庭）中执行长时程任务时，需要紧密协调基座导航与机械臂操作。模仿学习是解决该问题的有前景范式，但便携式演示接口（如腕部相机）面临两个耦合瓶颈：
- **动作标签污染**：添加胸相机后，人类行走与手部运动纠缠在一起，策略无法区分刻意手臂运动和行走引起的平移。
- **推理执行延迟**：扩散策略等生成模型引入数百毫秒推理延迟，在此期间移动基座向前移动，导致第一个预测路径点已位于当前位姿后方，执行时产生向后修正和抖动。

因此，本文提出 **Mobile UMI**——一个无需硬件设备（robot-free）的演示框架，旨在通过显式运动学分解和状态级延迟对齐解决这两个瓶颈，实现高效的移动模仿学习。

## 2. 方法论
### 2.1 核心思想
- **双摄像头采集**：操作员佩戴胸相机（全局导航上下文）和手持相机-夹爪模块（局部操作细节），均无需机器人。
- **空间锚点与解耦表达**：通过 ChArUco 棋盘一次标定统一胸和手视觉-惯性坐标系；将手部位姿相对于胸部重新表达（SE(3)），同时将胸部轨迹投影到地面得到 SE(2) 基座轨迹。这样操作和移动被显式分离。
- **交叉视角条件扩散策略**：以胸和手 RGB 图像、自身位姿及历史动作为输入，预测包含基座平移旋转、手臂 SE(3) 增量、夹爪开度共 11 维动作块（horizon=16）。
- **异步滚动时域执行 + 在线状态匹配**：后台预测时前台执行，接收新块后通过加权最近邻匹配当前实测位姿与预测状态，丢弃所有过期路径点（平均丢弃 3-4 个），避免轨迹回滚。

### 2.2 关键技术细节
- **视觉惯性里程计 (VIO)**：每个相机-IMU 节点独立运行 OpenVINS。
- **ChArUco 锚点**：对每个可见帧检测标定板位姿，最小二乘平均得到世界帧下的鲁棒估计，进而计算胸与手节点间的变换。
- **解耦公式**：\( T^{C_c}_{C_h}(t) = (T^{W_c}_{C_c}(t))^{-1} T^{W_c}_{C_h}(t) \)，消除共同移动成分。
- **非完整映射**：将胸的完整 SE(2) 轨迹投影到可行子流形 \( v_t = \dot{x}_t\cos\theta_t + \dot{y}_t\sin\theta_t,\ \omega_t=\dot{\theta}_t\)，丢弃横向分量并饱和滤波。
- **扩散模型**：余弦平方方差计划，100 步训练，10 步 DDIM 推理；使用 ResNet-18 编码器、FiLM 调节、1D 时间 U-Net。
- **状态匹配权重**：\( (w_b, w_t, w_r, w_g) = (1.0, 1.0, 0.2, 0.1) \)，对权重 ±2× 变化鲁棒（成功率波动 <2pp）。

## 6. 主要结论与发现
- Mobile UMI 平均成功率 **83.8%**，显著优于 Diffusion Policy (chest-relative) 的 66.8% 和 ACT (chest-relative) 的 51.5%。
- **解耦表示起主导作用**：仅切换标签（从全局到胸部相对）即让 Diffusion Policy 提高 14.3pp，ACT 提高 9.0pp。
- **延迟补偿必不可少**：禁用后降幅达 23.8pp，尤其对长轨迹任务（Book placement 降 25pp）。
- 方法无需改变底层策略架构（如扩散模型结构），仅通过数据表征和执行机制即可解决移动模仿学习瓶颈。

## 7. 优点
1. **完全免机器人演示**：双摄像头便携系统，操作员可在任何场景自由采集，无硬件物流开销。
2. **明确运动学解耦**：通过相对胸部表达自然分离行走和手部运动，使策略学习更聚焦局部操作。
3. **实用延迟补偿**：纯几何的状态匹配，不依赖动力学模型或约束求解器，简单有效。
4. **全面实验**：四个任务、数千次试验、系统消融，量化了每个组件的贡献，结果可信。
5. **低成本可复现**：仅需单块消费级 GPU 训练，开源硬件设计。

## 8. 不足与局限
1. **忽略动态力交互**：解耦表示假设动作与基座可分离，对于重载搬运（需基座抵消臂的反作用力）可能失效。
